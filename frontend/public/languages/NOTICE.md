# Language marks

Minimal flat adaptations from Devicon, MIT licensed.
Pinned source: https://github.com/devicons/devicon/tree/6a37858047b0e8d9c9c0e68f4a071fc410652e89

- Python: `icons/python/python-original.svg` — intertwined snakes.
- JavaScript: `icons/javascript/javascript-original.svg` — community JS square,
  not an official language-owned logo.
- Java: `icons/java/java-plain.svg` — coffee cup and steam.
- Go: `icons/go/go-original-wordmark.svg` — Go wordmark; excess vertical whitespace removed.

Geometry is preserved. Python gradients become flat blue/yellow theme fills;
JavaScript retains its yellow square and dark lettering. Java and Go use one
interface color.
The inline data in `frontend/lib/language-marks.ts` comes from these SVGs.
Names and marks remain the property of their respective owners.
