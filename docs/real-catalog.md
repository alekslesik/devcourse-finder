Подготовлен [data/real-catalog.json](../data/real-catalog.json): **20 программ, по пять для Go, Python, Java и JavaScript, 24 тарифа, все demo=false**. Это отдельный набор; демонстрационные записи и автоматический запуск приложения сохранены. Ни один каталог не импортируется при старте.

Официальные публичные страницы прочитаны при подготовке данных 05.10.2026 через веб-инструмент. Индивидуальные основания цены, набора, prerequisites и поддержки записаны в [машиночитаемой проверке источников](../research/catalog-review-2026-10-05.json). Такая проверка не подтверждает прохождение курса, качество обучения, оплату из конкретной страны или согласование партнёрской программы.

## Подтверждённые значения и границы

- 10 самостоятельных бесплатных программ. Цена 0 относится к полной указанной программе или открытому учебнику; платная профессия, преподавательские курсы и покупка электронной книги туда не входят.
- Две платные профессии Хекслета представлены тремя именованными тарифами каждая. Java: 85 000 / 119 000 / 189 000 ₽; frontend: 85 000 / 119 000 / 179 000 ₽. Это полная оплата, а не месячный платёж. Указанные суммы — наблюдавшиеся предложения на дату проверки. Срок подарка до 15 октября не принят за срок действия цены; срок самой скидочной цены в публичном тексте не подтверждён. Применяется обычное правило устаревания через 30 дней; перед публикацией и оплатой цены сверяются заново.
- У восьми платных программ полная стоимость не видна в полученном публичном тексте: price=null, price_kind=unknown, free=false. Они допускаются без ограничения бюджета, но исключаются при min/max, «только бесплатно» и «платные» с диапазоном. Месячные платежи и зарплаты выпускников не заменяют цену.
- У шести программ Яндекс Практикума текущий набор не подтверждён: enrollment=unknown. Они исключены из обычной выдачи и доступны при явном include_closed=true. Наличие программы в каталоге школы не считается открытым потоком.
- Нагрузка в неделю не вычисляется из общего числа часов, а недели — из месяцев. hours=12 сохранено только там, где это прямо указано для стандартного тарифа Хекслета. Разночтение общей длительности бесплатного JavaScript-курса Хекслета (50/62 часа) отмечено без выдуманной точности.
- Автоматическая проверка и ИИ-подсказки не считаются человеческим ревью или индивидуальными занятиями. Персональные консультации сохранены только для подтверждённых тарифов; базовые и премиальные варианты не смешиваются.
- Профили audience и goals — операторская классификация по prerequisites и назначению программы. Они не обещают трудоустройство и не заменяют вступительную проверку. Например, Code Basics Go требует хотя бы базовый другой язык, несмотря на общий рекламный ярлык «с нуля».
- Адреса официальные, без referral-параметров. Домены перечислены явно; партнёрские и закрытые данные в набор не включены. Детский курс Stepik 82867 исключён; истёкшая скидка OTUS до 27 сентября не используется.

## Явная публикация

Набор подготовлен для проверки оператором; production-публикация не выполнялась. Перед импортом пройти [регламент](catalog-operations.md) и заполнить отдельный [протокол](catalog-publication-record.md) в release-хранилище. Повторно проверить источники, текущие цены, набор и соответствие тарифов; запись от 05.10.2026 не является вечным подтверждением актуальности.

```sh
export CATALOG_FILE="$PWD/data/real-catalog.json"
export CATALOG_OPERATOR="your-stable-operator-id"
docker compose run --rm --no-deps \
  --volume "$CATALOG_FILE:/data/catalog.json:ro" \
  api catalog validate /data/catalog.json
```

Создать backup по регламенту, затем отдельно запустить и проверить dry-run:

```sh
docker compose run --rm \
  --volume "$CATALOG_FILE:/data/catalog.json:ro" \
  api catalog import /data/catalog.json --dry-run
```

После проверки diff импортировать этот же файл без --dry-run и проверить API/интерфейс, источники, сравнение, переходы и аудит. Набор рассчитан на пустую production-базу либо уже проверенную базу реальных записей. Импорт не удаляет отсутствующие программы: если ранее загружался demo-каталог, оператор должен отдельно подготовить и проверить явное архивирование этих записей; обычный импорт real-catalog не заменяет demo-строки.

Минимальная проверка после импорта: include_closed=true&page_size=48 возвращает 20 программ, по 5 каждого языка; сравнение hexlet-java-standard, hexlet-java-premium и codebasics-java-course сохраняет разные цены и поддержку; /out/hexlet-java-standard ведёт на официальный URL. Обычная выдача сейчас содержит 14 программ, потому что шесть наборов неизвестны. Неподтверждённые цены и истёкшая проверка должны продолжать исключаться при ограничении бюджета.

## Проверки

- TestRealCatalogHasReviewedAdultPrograms: валидная схема, минимум 20 записей / 5 каждого языка, отсутствие демоданных и example.com, индивидуальная запись проверки для каждой программы, дата/URL/обязательные основания совпадают.
- TestRealCatalogCLIImportAndPublicHTTP: настоящие CLI-процессы и PostgreSQL 17, dry-run без изменений, два импорта без дублей (20/24), HTTP/OpenAPI по четырём языкам и всем страницам, точные копейки и поддержка тарифов в сравнении, безопасный официальный redirect.
- [Локальная репетиция публикации и восстановления](real-catalog-staging-2026-10-05.md): отдельная пустая БД, настоящий CLI, backup и restore с полным совпадением каталога, тарифов, аудита и settings.

CI проверяет подготовленные файлы без сетевых запросов к школам. Актуальность источников оператор повторно проверяет перед каждой публикацией; недоступность школы не должна превращать CI в случайный сетевой тест.
