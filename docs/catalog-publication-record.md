# Протокол публикации production-каталога

Скопируйте этот файл во внешнее хранилище release-артефактов для каждой публикации и заполните все поля. Не коммитьте заполненный протокол, если в нём есть закрытые пути, имена операторов или сведения о партнёрских ссылках.

Порядок выполнения команд и правила принятия решений определены в [регламенте публикации каталога](./catalog-operations.md). Пустой шаблон не подтверждает публикацию: подтверждением считается только заполненный протокол с приложенными логами и контрольными суммами.

## Проверка источников

- [ ] Для каждой изменённой программы проверен официальный источник.
- [ ] Проверены полная цена, формат, статус набора и дата проверки.
- [ ] Неподтверждённые или устаревшие значения не обозначены как точные.
- [ ] Домены источников и переходов входят в `approved_domains`.
- [ ] Партнёрские ссылки не влияют на порядок выдачи.

## Проверка после публикации

- [ ] `/health/ready` возвращает HTTP 200.
- [ ] Проверена выдача хотя бы по одной изменённой программе каждого языка.
- [ ] Проверены бесплатное и платное предложения.
- [ ] Проверены фильтры цены и поддержки.
- [ ] Проверен ответ программы.
- [ ] Проверено сравнение двух тарифов.
- [ ] Проверен переход через `/out/{offer_id}`.
- [ ] Изменения появились не позднее 60 секунд после импорта.
