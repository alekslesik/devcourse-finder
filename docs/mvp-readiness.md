**Проверено локально** — требуемая реализация есть и относящиеся к ней локальные проверки прошли. **Частично** — остаются требования или существенные проверки. **Не выполнено** — результата по требованию пока нет.

## Оставшаяся приёмка

- Нагрузка: 10 000 предложений, 20 запросов, стенд 2 vCPU/4 GB, прогрев 1 минута, замер 5 минут, p95 ≤500 мс.
- Полные HTTP/contract-тесты реального Go API, включая внешний переход при отказавшей аналитике.
- Браузерная приёмка с настоящим Go API и PostgreSQL, а не fixture API.
- Полная ручная приёмка AC-01—AC-20, включая быстрые конкурирующие поиски и все правила цен.
- Проверка старых модальных сценариев и полного управления фокусом.
- 20 проверенных реальных программ: демонстрационные записи не подходят для production.
- Установка ежедневного резервного копирования и контроля его отказов на production.
- Слияние изменений и зелёный CI для release commit.
