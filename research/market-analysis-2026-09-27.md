# Рынок обучения разработчиков: Go, Python, Java и JavaScript

Дата исследования: 27 сентября 2026 года.

## Результат и границы

Составлена карта **33 площадок, школ и образовательных проектов** с платными и бесплатными предложениями. Это каталог обнаруженного предложения и анализ для будущего сервиса подбора, а не рейтинг качества обучения и не полный реестр всех курсов России.

Под «в России» здесь понимается прежде всего русскоязычное предложение для аудитории российского рынка. Юрисдикция, возможность заключить договор и оплатить обучение из РФ не проверялись для каждой организации. Международные русскоязычные ресурсы отмечены отдельно.

Включены взрослые начинающие и действующие разработчики; основы языков, backend, frontend и Node.js. TypeScript учитывается внутри JS-направления. Исключены из основного сравнения детские занятия, ЕГЭ, QA, чистая аналитика/Data Science, DevOps без разработки, полноценные бакалавриаты и магистратуры. Пограничные программы явно отмечены.

Сведения о наличии программ получены из официальных каталогов, лендингов и извлечений официальных страниц в поиске. Часть страниц прочитана целиком инструментом, часть подтверждена только индексируемым официальным текстом. **Наличие страницы не доказывает открытый набор.** Цены ниже — снимки опубликованных предложений, а не проверенные суммы на этапе оплаты.

Единица будущего каталога: **конкретная программа + тариф + формат**, а не школа целиком. Stepik, Поколение Python и другие авторы не являются независимыми непересекающимися рынками: один курс может присутствовать в нескольких представлениях.

## Основные выводы для нашего продукта

1. Для всех четырёх языков найдены и бесплатные материалы, и платные программы. Поэтому польза сервиса должна заключаться в подборе под задачу, а не в самом наличии списка ссылок.
2. Самое существенное деление — **основы языка / первая профессия / переход с другого языка / повышение квалификации**. Цена без этого деления вводит в заблуждение.
3. По JS нужно отдельно показывать frontend и Node.js backend. По Python — отделять разработку приложений от аналитики и машинного обучения.
4. Бесплатные материалы — полноценная часть выдачи. Но нужно различать полный открытый курс, вводный модуль, демодоступ и обучение с отбором.
5. В этой проверке подтверждены публичные денежные партнёрские программы Практикума, Skillbox и Нетологии. Для остальных денежная монетизация не считается подтверждённой.
6. В открытых описаниях есть расхождения сроков, акций и названий. У каждой записи нужны источник, дата проверки и статус достоверности.
7. Опубликованные отзывы, зарплатные обещания и проценты трудоустройства не дают оснований присваивать школам собственный рейтинг качества.

Это выводы из собранного предложения. Размер спроса, поисковая конкуренция, стоимость привлечения и доходность сайта в этом исследовании не измерялись.

## Разбор по языкам

### Go

В найденной выборке хорошо различимы две задачи: вход в профессию и развитие уже работающего разработчика.

**Первая профессия:** Практикум, Нетология, Skillbox, OTUS Basic, Бруноям, Kata. Их нельзя автоматически рекомендовать по слову «с нуля»: сначала проверяются требования, темп, длительность и объём самостоятельной работы. Официальные страницы: [Практикум](https://practicum.yandex.ru/go-developer-basic/), [OTUS Basic](https://otus.ru/lessons/go-basic/), [Kata](https://kata.academy/courses).

**Переход и развитие:** Хекслет маркирует Go как продвинутый; Слёрм предлагает прикладной сервис; Balun — внутреннее устройство языка и специализации; у OTUS есть продвинутый уровень. Это разные результаты: освоить второй язык, собрать сервис, понять runtime или подготовиться к интервью. [Хекслет](https://ru.hexlet.io/courses_programming), [Слёрм](https://slurm.io/go), [Balun](https://balun.courses/courses/deep_go).

**Бесплатное начало:** Stepik «Программирование на Golang», Code Basics, METANIT; у Практикума — отдельные основы. В описании Stepik предполагается базовый опыт программирования. У Code Basics общий ярлык «с нуля» расходится с текстом про уже умеющих программировать — в нашем каталоге приоритет должен иметь подробный prerequisite. [Stepik](https://stepik.org/course/54403/promo), [Code Basics](https://code-basics.com/ru/languages/go).

Что сравнивать в Go: горутины и каналы, context и отмена, обработка ошибок, HTTP, SQL, тестирование, race detection, профилирование, проект и ревью. Это предложенная методика сравнения, а не утверждение о наличии каждого пункта у всех школ.

**Вывод:** для первого ручного подбора тебе ближе аудитория «уже программирую, хочу перейти на Go». Это гипотеза, основанная на твоём опыте, а не доказательство более высокого спроса.

### Python

Для каталога разработчиков нужен отдельный фильтр **backend / основы и автоматизация**. Школа может продавать Python в контексте аналитики; такая программа не становится backend-курсом только из-за языка.

Платные backend-предложения обнаружены у Практикума, Нетологии, Skillfactory, Хекслета, Skypro, ProductStar, Eduson и других перечисленных площадок. У Практикума текущая карточка прямо посвящена backend, у Eduson указан Python/Django. [Практикум](https://practicum.yandex.ru/backend-developer/?from=catalog), [Eduson](https://eduson.academy/python).

Бесплатные основы доступны у Поколения Python, Института биоинформатики на Stepik и Code Basics. Они дают альтернативу покупке первого курса, но сами по себе не подтверждают подготовку к промышленной веб-разработке. [Поколение Python](https://stepik.org/course/58852/promo), [Институт биоинформатики](https://stepik.org/course/67/promo), [Code Basics](https://code-basics.com/ru/languages/python).

Что сравнивать: Python Core, ООП, Django/FastAPI/Flask, SQL и ORM, HTTP/API, pytest, развёртывание, фоновые задачи; отдельно — содержание реальных самостоятельных проектов. Не начислять баллы только за количество упомянутых фреймворков.

**Вывод:** общая страница «лучшие курсы Python» будет слишком широкой. Полезнее подбор «хочу писать backend, знаю основы, нужна проверка кода».

### Java

Здесь есть и многопрофильные школы, и специализированные маршруты: JavaRush, TopJava, Kata. У JavaRush отдельно существуют тренажёр и University; у TopJava — последовательные ступени. Они не взаимозаменяемы по поддержке и подготовке. [JavaRush](https://javarush.com/courses), [TopJava](https://topjava.ru/).

Бесплатный базовый Java на Stepik предполагает знание другого императивного языка и описывает Java 8. Его корректно показывать как основы языка с указанной версией, а не как полный современный Spring/backend-трек. [Курс Stepik](https://stepik.org/course/187/promo).

Что сравнивать: Java Core, коллекции, generics, многопоточность, JVM, SQL, Spring Boot, тестирование, сборка, REST, командный проект. Версию JDK и фреймворков хранить отдельно; отсутствие самой новой версии не означает автоматически плохой курс.

**Вывод:** сильная задача подбора — «знаю Java Core, но не понимаю, какой курс даст практику backend и ревью».

### JavaScript

В каталоге должны быть минимум три ветки: **основы JS**, **frontend с React/Vue**, **backend на Node.js**. Fullstack — отдельная комбинация, не синоним любого JS-курса.

Специализированные предложения найдены у HTML Academy, learn.javascript.ru, PurpleSchool и Result; более интенсивный формат — у Эльбруса. У HTML Academy различаются тренажёры, lite, профессии и профессиональные модули. [HTML Academy](https://htmlacademy.ru/profession/react), [learn.javascript.ru](https://learn.javascript.ru/courses/js), [Эльбрус](https://elbrusboot.camp/).

Бесплатные альтернативы: учебник learn.javascript.ru, Code Basics и RS School. Последняя — международное сообщество, поэтому её не нужно описывать как российскую коммерческую школу. [Учебник](https://learn.javascript.ru/), [Code Basics](https://code-basics.com/ru/languages/javascript), [RS School](https://rs.school/courses/javascript).

Что сравнивать: JS Core, DOM, асинхронность, HTTP, TypeScript, тесты; далее отдельно React/Vue и frontend-проекты либо Node.js, API, базы данных и backend-проекты.

**Вывод:** здесь особенно полезно объяснять отличие «учу язык» от «учусь делать frontend» и «делаю сервер на Node.js».

## Как оценивать качество без выдуманного рейтинга

По открытым страницам можно сравнить **заявленную программу**. Чтобы сравнить фактическое обучение, потребуется пройти демо и изучить примеры проверки работ. Поэтому сейчас у школ нет оценок «лучше/хуже».

Для каждой программы фиксировать:

1. Кому подходит и какие входные знания нужны.
2. Заявленный результат: основы, смена профессии, второй язык, повышение квалификации.
3. Темы и версии технологий; дата проверки программы.
4. Практика: автотесты, самостоятельные проекты, командная работа.
5. Ревью: кто проверяет, насколько подробно, сколько итераций, есть ли пример.
6. Поддержка: индивидуальная или групповая, частота, сроки ответа.
7. Нагрузка: часы в неделю и обязательное расписание, а не только месяцы.
8. Полная цена, тариф, срок доступа, отдельная цена платежного плана.
9. Набор: открыт, закрыт, постоянный доступ или неизвестно.
10. Карьерная помощь: конкретные действия вместо общего слова «трудоустройство».
11. Источник и статус: официальное заявление / просмотрено демо / подтверждено дополнительными материалами.
12. Монетизация: программа найдена / заявка одобрена / условия конкретного оффера подтверждены.

Число проектов и длительность сами по себе не определяют качество. Один самостоятельный проект с подробным ревью может быть полезнее множества упражнений по готовому шаблону — это основание для проверки, а не установленный результат сравнения школ.

## Что это означает для первой версии сервиса

Предлагаемая структура:

- Выбор цели и исходного опыта.
- Язык, направление, бюджет **за весь курс**, доступное время.
- Отдельная возможность показать бесплатные материалы и курсы с отбором.
- Результат из 2–3 подходящих вариантов с объяснением соответствия и ограничений.
- Сравнение формата практики и поддержки.
- Прямая ссылка на источник и дата проверки.

Не нужно начинать с автоматического ранжирования всех 33 площадок. Сначала вручную проверить несколько конкретных программ в каждом языке и помечать остальные как каталог обнаруженных предложений.

**Предложение для проверки спроса:** держать четыре направления в исследовательской базе, а первые интервью разделить на четыре группы. Сравнить, кто реально выбирает обучение сейчас, какие альтернативы рассматривает, в чём затруднение и использует ли результат ручного подбора. Не выбирать язык только по обещанной комиссии или количеству найденных школ.
